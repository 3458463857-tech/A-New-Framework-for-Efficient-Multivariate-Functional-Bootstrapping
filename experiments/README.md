# Experiment material

Start with the root `TABLE_INDEX.csv`, which identifies exactly which records
support each reported timing. A group may also contain build logs, correctness
checks, offline decompositions, or diagnosis records. Those files are not
additional timing results unless the index selects them.

Use `../docs/Reproduction_Guide.md` to prepare a separate workspace and run the
programs. Run scripts from that workspace, not in this preserved collection.
Parameter constants are retained in source and source snapshots; the public
Supplementary Notes explain their interpretation and comparison limits.

Superseded timed runs are under `../archive/historical_results/`. Supporting
definitions and offline evidence remain in `supporting_materials/`.
