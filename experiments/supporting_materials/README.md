# Supporting source and checks

`classical_functions/` retains shared function definitions and input lists used
by the current baseline runners. Its older ciphertext measurements have been
separated into the historical archive.

`initial_implementation/` retains the original source, offline representation
search, finite verification, and structural examples. Its offline-search
comparison is supporting evidence; superseded ciphertext timings are archived.

These files must not all be classified as unused history: some are dependencies
or evidence for the current paper. Final online means are selected separately
by the root `TABLE_INDEX.csv`.
