# Independent rerun

```text
python run_experiments.py --output-dir verification_rerun
```

All 76 rows were regenerated. The following scientific fields were compared
row by row with `../results/all_results.csv` and were identical:

`family`, `function`, `parameters`, `construction`, `direct_records`,
`output_cardinality`, `decomposed_records`, `compression_ratio`, `lut_calls`,
`reachable_states`, `exhaustive_cases`, `maximum_error`, `exact`, `selected`,
`scale`, and `note`.

Only `elapsed_ms`, which is machine-load dependent, was excluded from the
comparison. Both runs selected 45 of 76 candidates under the mechanical rule.
