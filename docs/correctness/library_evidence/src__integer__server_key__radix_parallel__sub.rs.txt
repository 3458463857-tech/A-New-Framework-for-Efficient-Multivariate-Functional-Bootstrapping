151:     ///
152:     /// This function, like all "default" operations (i.e. not smart, checked or unchecked), will
153:     /// check that the input ciphertexts block carries are empty and clears them if it's not the
154:     /// case and the operation requires it. It outputs a ciphertext whose block carries are always
155:     /// empty.
156:     ///
157:     /// This means that when using only "default" operations, a given operation (like add for
