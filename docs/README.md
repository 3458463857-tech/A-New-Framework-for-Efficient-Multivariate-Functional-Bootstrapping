# Documentation

- [Supplementary Notes](Supplementary_Notes.pdf): retained technical detail,
  parameters, timing protocol, and limitations. The S1–S4 topics preserve the
  cross-references used by the frozen paper.
- [Reproduction Guide](Reproduction_Guide.md): preparation, dependencies, and
  commands for checking saved records or running selected experiments.
- [Function Catalogue](../functions/Function_Catalogue_and_Verification_Records.pdf):
  definitions, evidence groups, and applicability guidance for the supplied function examples.
- [Applicability update](Applicability_Update.md): explanation of the documentation-only update and the unchanged evidence.
- `provenance/`: original-file checksums and the workspace copy plan.
- `correctness/`, `construction_certificates/`, `nested_construction/`, `theory/`:
  retained source and finite-check records. Directory names inherited from
  earlier code do not imply formal security certification.

Only `../TABLE_INDEX.csv` selects final performance results. Finite checks and
successful ciphertext trials do not establish a calibrated failure probability.
